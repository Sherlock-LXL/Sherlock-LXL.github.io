# 素材与来源 / Assets and provenance

[中文](#中文) · [English](#english)

## 中文

素材台账用于追溯，运行读取 `modules/<id>/assets/` 中的项目副本。

- `research/`：两篇论文原稿与导入记录。
- `audio-wav/`：四份无损音频存档。
- `metadata/`：摄影与音乐来源、歌词哈希、音频标准化记录。

来源中的历史机器路径不作为运行依赖。歌词与专辑资料保存在模块清单。

## English

Provenance records trace the originals; runtime uses project copies in `modules/<id>/assets/`.

- `research/`: two original papers and import records.
- `audio-wav/`: four lossless audio archives.
- `metadata/`: photo/music sources, lyric hashes and audio normalization records.

Historical machine paths are provenance only. Lyrics and album information live in module manifests.
