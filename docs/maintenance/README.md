# 第一轮目录清理 · 2026-09-11

当前产品版本保持 v0.19.0。完整成品保留在 `build/XiangMeta-0.19.0/`，EXE 的 SHA256 未改变：`029375e8687011e86082a6583b741e1227b86a5148a5645d7b5d68b13ce0a1a9`。

## 清理结果

- 删除 20 个构建根目录 EXE（旧版本及当前重复单文件）、8 个旧版便携目录及其中重复模型环境、解包中间件、旧虚拟环境、早期一次性迁移脚本、旧测试截图与测试 profiles。
- 主要删除清单共 183,780 个文件，约 31.539 GiB。完成新依赖复制与当前记录保留后，项目目录净减少约 31.51 GiB；统计仅计普通文件字节，不包含文件系统分配差异。
- 所有版本说明及原有发布文本已归档到 `docs/releases/`。图片、模型、音乐原文件所在的工程外目录未改动。
- 保留源码开发环境与当前便携环境各一份；保留开发依赖、当前 dist、全部已用媒体、论文原稿、无损音频和维护台账。
- 当前配置集中到 data；来源/转换台账移入 asset-sources/metadata；当前验收图片和报告集中到 artifacts/current。
- 后续打包的中间输出改为 build/staging，完整成品仍放 build/XiangMeta-<版本>，避免与发布目录混杂。

## 外部依赖复核

开发和便携目录的五个模型、解释器、模型必需文件、58 个本地媒体 URL、两份论文和 FFmpeg 已复核。模型库存哈希匹配；便携模型和解释器必须位于自己的发布目录内。

游戏运行未发现遗漏的外部资产。维护工具缺少 lxml 6.1.1，已从已有环境只读复制进 runtime/python，包含许可和包信息，共 209 个文件、9,378,703 字节；完整复制及哈希记录在 copied-dependencies.json。用本地 Python 重新提取两篇论文，结果与 src/core/research-content.json 一致。无需依赖原缓存 Python。

原始 Pictures/Programme/GitHub 地址仅保留在历史资料与来源台账中；活动配置和默认维护流程已移除固定机器路径。用户主动导入新专辑时用 --source 明确指定新的输入目录。
