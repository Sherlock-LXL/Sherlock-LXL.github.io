# GitHub 发布准备 · 1.0.0

当前版本仍为 **1.0.0**。本轮只调整春日花灯位置、AI 山脉标牌石座和侧栏文字。

## 源码仓库

在项目根目录初始化 Git 后提交源码即可。`.gitignore` 已排除开发依赖、构建输出、检查截图、本地配置、独立 Python、模型权重、无损音频与论文原稿；这些文件仍保留在本地。

`modules/`、`public/` 中实际用于展示的照片、歌曲与视频会随源码提交。不要使用强制添加将整个 `runtime/` 或 `build/` 塞进源码仓库。发布前在 Git 客户端查看待提交清单。

首次获取源码需安装 Node.js 依赖；完整本地推理还需成品中的 `runtime/` 与 `local.json`。源码本身不包含模型权重和 Python 安装环境。模块契约与开发方法见根目录 README。

## Windows 成品

成品位置：`build/XiangMeta-1.0.0/`。

分发时打包整个文件夹，保留 EXE、`runtime/`、`local.json`、`使用说明.txt` 和 `SHA256.txt`。单独下载 EXE 无法获得五个本地模型。较大的运行环境可以单独压缩分发，解压后保持同一目录结构。

GitHub Release 的标题可用 **XiangMeta 1.0.0 · 一个持续生长的世界**，介绍可采用下方文字。最终 EXE 校验值见 [SHA256.txt](releases/1.0.0/SHA256.txt)。

> XiangMeta 是一个可以走进去的个人数字世界。沿着春日 AI 山径体验五个本地模型，在冬日科学山谷探索气泡与声致发光，在秋日展廊欣赏摄影和原创专辑，在夏日未名拾音工作室观看《燕来有声》。世界包含昼夜、天气、音乐、摄影模式、记忆星图与探索互动，并通过模块契约为未来项目保留扩展空间。
>
> Windows 版请解压完整成品后启动 XiangMeta-1.0.0-x64.exe，保留旁边的 runtime 和 local.json。WASD 移动，空格跳跃，F 使用展品，R 体验互动，P 进入摄影模式。

本轮没有执行远程发布，也没有创建 Git 仓库、提交、标签或指定开源许可证。
