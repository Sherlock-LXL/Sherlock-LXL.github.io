# v0.8 · 山径与远方

v0.7 已交付并保留。本版将成长顺序落实为可行走的山体，加入具有独立建筑语言的量化交易所岛和机器人岛。

## 从山脚到山顶

| 台地 | 项目 | 标高 |
|---|---|---|
| 01 | 礼物选择器 | 1 米 |
| 02 | CNN 表情识别 | 4 米 |
| 03 | RNN 双盲诗 | 7 米 |
| 04 | CNN 猫咪识别 | 10 米 |
| 05 | Transformer / XiangLM | 13 米 |

AI 山脉扩大为半径 26 米的山岛，平缓台地通过连续山坡相连。金色山径从入口接向成长路线，蓝色视觉捷径连通两座 CNN 台地，沿路有柔光地灯。展台前方保持平坦，F 工作台、快速传送、跳跃和模型调用继续可用。

主成长路线约 77 米，CNN 捷径约 17 米，均使用真实世界的障碍网格规划。两条路线已通过角色物理积分的双向行走验证；捷径确实短于经诗园的路线。山体造型、角色地面、展台高度、碰撞、记忆标记和分区效果读取同一高度函数，跳跃不会穿入上升地形。

表情识别增加一段基于已有项目档案的记忆，总数变为九段。原八段记忆 ID 保持稳定，旧进度继续有效。成长顺序遵循本版策展要求，不冒充精确履历时间线。

## 两座未来岛屿

**量化投资交易所岛**：港湾基座、柱廊、中庭、圆顶和行情柱雕塑。建筑是未来项目的概念空间，雕塑不代表实时行情，也未连接券商或交易账户。

**机器人岛**：机器人地标、双工坊、机械臂和夜间柔光窗。它为未来机器人与具身智能项目预留空间。

左侧「远方岛屿」和地图虚线标签可打开说明，再进入预设的远眺摄影视角。支持选择昼夜、自由移动、导出照片和带岛屿名称的明信片；返回后恢复原角色位置。这两座岛目前尚未开放步行进入。研究院和城市剪影继续保留。

## 验证与性能

- 26 项单元/网关测试通过，包括地形标高、不同帧率下的坡面移动、跳跃、防穿透、模型输入和生命周期。
- mountain-world：五站顺序、各层传送/F/跳跃、上下山、双向捷径、两座远景的摄影进入与角色恢复。
- 浏览器回归：十个产品工作台、真实推荐推理、摄像头清理、四区传送。
- discoveries / jump-browser：真实诗歌与字体、四种 R 装置及存档、声音、减少动态效果偏好、跳跃与高台落地。
- movement：行走约 5.30 米/秒、加速约 8.49 米/秒，碰撞停止后仍可 F 交互。

固定 1280×800 测试视口的短时样本约为行走 80 FPS、总览 75 FPS；平均绘制调用约 134 / 468（含定期阴影通道）。这是本机样本，不是稳定帧率保证。山体是一张高度网格，未来建筑与沿路静态细节继续合批，没有大量新增动态灯光。
