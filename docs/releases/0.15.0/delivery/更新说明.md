# v0.15 海风港口

## 阴天修复

v0.14 的透明球形云幕与透明云团按对象中心排序，相机转动时可能交换绘制顺序。现将高空云幕改为固定世界坐标的水平云层（高度 82 米），噪声直接采样世界坐标，仅受风速和时间推动。下层云团写入深度，高空云幕保持深度测试，避免抬头时忽然覆盖或显露云团。太阳、月亮与星空位于云幕之后。

云团轮廓增加细分；阴雨降低云团高度、加深颜色，雪天保持浅色覆盖。云幕颜色、风向和覆盖率仍连续过渡，晴天跳过不可见的云幕绘制。雨雪粒子沿用局部降水范围，摄影模式暂停所有天空运动。

`tests/cloud-depth.mjs` 使用真实 WebGL 像素采样：三个相机方向的前景云团，在开启/关闭后方云幕时中心像素一致；观察者移动不改变云幕位置。`tests/weather-v13.mjs` 覆盖天气流转与摄影暂停。

## 海风港口

从中央枢纽南侧沿缓坡栈桥下行，可以抵达靠近海面的候船平台。包含木甲板、缆绳护栏、系船柱、救生圈、雨棚服务台和随海浪轻微起伏的泊船。

靠近柜台按 F，或从侧栏打开海风港口，可以查看三条筹备航线：量化投资交易所岛、机器人岛、AI 研究院。目的地均明确标记尚未开放，乘船按钮禁用，不会实际传送，也没有虚构的解锁日期。界面提供“去栈桥走走”。

布局与步行地形共用 `shared/harbor.mjs`，世界组件为 `src/world/harbor.ts`。坡道由 0 米降至 -4.6 米；修正了旧行走系统强制把负高度提升到 0 的限制。相同碰撞与重力逻辑覆盖下坡、上坡、跳跃和平台边缘。

## 材质与渲染

- 木材、石材、铺装、金属、灰泥使用共享的细节法线与粗糙度贴图，区分纤维、矿物颗粒、砖缝和拉丝反光。
- 材质按米尺度映射，不再让一张小纹理拉伸覆盖整面大墙；静态合批保留，未添加逐帧纹理生成。
- 岛屿底座使用岩层饰面，季节地面加入沙纹、细雪和草地微表面。
- 用一次预计算的低强度环境反射改善金属、玻璃与陶瓷，不采用逐帧实时反射。反射强度随昼夜和天气变化。
- 哑光墙面和地面跳过环境反射采样，静态合批明确区分法线、粗糙度贴图与着色器，避免不同表面细节被误合并。
- 接触阴影绘入已有地面纹理，避免新增重叠地面平面；也修正了旋转展馆仍把入口圆形铺装画在旧朝向的问题。
