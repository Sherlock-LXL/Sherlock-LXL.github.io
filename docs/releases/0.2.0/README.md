# XiangMeta v0.2：第一人称探索与产品工作台

本版保留原有模块契约、模型网关与传送入口，将默认视角改为第一人称，并按步行探索的尺度补充区域环境。

## 操作

- 默认从 AI 山脉入口开始，视线高度 1.7 米、视野角 68°；不添加强制镜头摇晃。
- WASD / 方向键行走，Shift 加速。移动方向随视线朝向变化。
- 点击画布或「点击进入环顾」锁定鼠标，移动鼠标环顾；Esc 释放鼠标。也可按住左键或触摸拖动环顾。
- 靠近展品前的交互终端，在 2.9 米内显示「F / 交互」。以最近终端为准，离开范围自动隐藏。
- 按 F 直接打开产品工作台；输入与输出并排显示。生成、上传、相机、参数与科研示意仍使用原模块接口。
- 工作台开启时释放鼠标并暂停行走。关闭或按 Esc 后继续探索，不自动重新捕获鼠标。
- 「世界总览」进入独立俯瞰地图，允许旋转/缩放；右下角按钮恢复当前位置的第一人称。
- 原有区域传送与「抵达展台」保留。落点面向终端，并检查地面和障碍物。

## 区域设计

`data/world.json` 的 `scenery` 选择区域环境，新增项目仍无需修改核心。

| 类型 | 本版环境 |
|---|---|
| woodland | 分层山峰、花园灯笼、树木与花簇、塔体细节 |
| laboratory | 仪器柜、后场设备廊、金属管道、观测环 |
| museum | 柱廊、顶棚灯带、雕塑与艺术标牌 |
| studio | 录音棚立面、声学板、座椅、音箱与麦克风 |

各区共用路灯、座椅、种植池、岸边栏杆、步道、区域门牌与产品终端。入口和通道保持可通行，树干、展品、终端与部分墙体有基础碰撞。

## 工程结构

- `src/world/look-controls.ts`：鼠标锁定、拖动环顾与生命周期。
- `src/world/world.ts`：第一人称/地图切换、导航、传送、近距离交互。
- `src/world/scenery.ts`：区域环境、路径、门牌与产品终端。
- `shared/interaction.mjs`：统一视线高度、交互距离、最近终端选择与朝向计算。
- `src/main.ts` 与样式：F 提示、产品工作台、输入/结果布局与退出。

新增最近终端、交互距离、朝向、墙体与终端碰撞测试；浏览器验证第一人称、传送、F 入口、工作台期间停止移动、收藏、科研交互及模型调用。实体摄像头效果与不同鼠标/GPU 仍以设备实际体验为准。

当前环境仍是程序化风格化模型，GLB 替换机制不变。没有加入复杂刚体、跳跃或完整室内物理。
