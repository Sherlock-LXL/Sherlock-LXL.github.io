# XiangMeta 0.2.0 · 第一人称与工作台 / First-person workbenches

[中文](#中文) · [English](#english)

## 中文

默认第一人称探索，增加近距离 F 工作台、分区布景、基础碰撞与独立总览相机。

### 验证

11 组自动测试及十个展台浏览器回归通过；Windows 成品实测启动与原礼物模型调用。

[技术与验收记录](notes.md)保留当时的操作、参数、指标、SHA 和验证范围。旧构建路径仅作历史记录；当前运行方式见[主 README](../../../README.md)。

## English

Made first-person exploration the default, with nearby F workbenches, regional scenery, basic collision and a separate atlas camera.

### Validation

Eleven automated test groups and browser regression across ten stations passed; the Windows build was launched and ran the original gift model.

[Technical and validation notes](notes.md) retain the original controls, parameters, metrics, hashes and test scope. Build paths are historical; see the [main README](../../../README.md) for current usage.
