# v0.9 · 山地花园

本轮重新设计 AI 山脉的路径与台地，并统一世界中的表面细节。保留现有展品顺序、独立 AI 接入和访客存档。

## 场景

- 浅金色主路宽 3.2 米，沿五层展区折返上山；曲线转弯取代网格折线。
- 展区前设置圆形铺装驿站、编号路牌；镜子房间和猫咪森林附近有休息长椅。
- 路旁木护栏配圆形柱帽及夜间柔光，花带位于铺装外缘和护栏之间。入口、转弯平台与路口留空。
- 两座 CNN 台地之间有 1.9 米宽的蓝色视觉捷径及双向指路牌。
- 山体使用圆角台地、石砌挡墙、草地与岩壁分区材质。岩壁使用三向投影，避免陡坡纹理被拉成条带。
- 纸蝶来信移到山脚驿站旁；原 R 交互及收藏记录继续保留。
- 全世界共享细砂墙面、石纹、木纹、金属细纹和低对比草叶纹理；地面铺装加入砖缝与轻微色差，其它区域的花槽补充有花瓣、花茎和叶片的花簇，长椅增加靠背。

## 实现与维护

`shared/mountain-route.mjs` 负责配置路线的圆滑采样；`shared/terrain-height.mjs` 同时供地形网格、步行、传送及装饰采样。驿站覆盖范围内保持平整，其余路线按高度剖面升降。道路不再依赖寻路网格生成外形。

`src/world/garden-routes.ts` 根据区域清单生成道路、护栏、花带、驿站和挡墙。铺装由贴地网格按路线距离裁切，避免急弯带状网格自相交，以及路面跨过凸起平台时出现草地穿出。护栏使用线段胶囊碰撞；寻路器检查网格边的连续通行性，避免节点之间穿过细护栏。

`src/world/surfaces.ts` 缓存少量 512×512 程序纹理；花朵通过实例绘制，静态建筑继续按材质合批。地面细节画在同一纹理中，减少重叠地面闪烁。

配置入口及扩展约定见 [World Module Contract](../../world-module-contract.md)。本轮无需图片下载或修改原模型仓库。

## 验证

通过 TypeScript 和生产构建、28 项单元测试，以及浏览器中的五展品上下山、主路/捷径双向通行、F 交互、高处传送和跳跃落地验证。回归覆盖真实模型调用、Esc 恢复环顾、四种旅行印记、九段记忆、摄影导出与昼夜系统。

步行实测约 5.19 米/秒，跑步约 8.46 米/秒。Edge 无头模式、1280×800、120 帧的最终抽样：近景约 53.5 FPS / p95 25.8 毫秒，地图约 63.6 FPS / p95 24.9 毫秒；平均绘制调用约 179 / 476。完整记录位于 `artifacts/performance-v0.9.json`。本轮比 v0.8 增加了材质与几何成本，尚未达到近景稳定 60 FPS；测试环境的帧率也不能视为所有电脑上的保证。已将额外凹凸计算限制在石材及铺装，并将缓慢日月轨道的阴影重绘降至每秒 5 次；相机和角色仍逐帧更新。

已启动真实 Windows 便携版，验证解包启动、十个展品、真实模型调用、原生空格跳跃、R 收藏、摄影、昼夜设置与 Esc 恢复鼠标锁定。测试后已恢复原始访客存档并关闭测试窗口。成品大小 86,645,973 字节，校验文件为 `build/XiangMeta-0.9.0-x64.sha256`。
