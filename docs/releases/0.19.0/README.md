# XiangMeta 0.19.0 · 雨幕与留白 / Rain and clear space

[中文](#中文) · [English](#english)

## 中文

7200 个雨滴采用独立随机采样与一次绘制；撤去不满足留白的山路座椅，重新布置二十八处浅雪堆与护栏。

### 验证

50 项单元检查、雨幕及完整轮廓避让、路线和十六装置实走通过；63 个文件一致，本轮未测 Windows 物理 Esc。

[技术与验收记录](notes.md)保留当时的操作、参数、指标、SHA 和验证范围。旧构建路径仅作历史记录；当前运行方式见[主 README](../../../README.md)。

## English

Rendered 7,200 independently sampled raindrops in one draw, removed mountain seats without adequate space and revised twenty-eight shallow snow patches and rails.

### Validation

Fifty unit checks, rain and full-footprint clearance, routes and sixteen installations passed; 63 files matched. Physical Windows Esc was not tested in this round.

[Technical and validation notes](notes.md) retain the original controls, parameters, metrics, hashes and test scope. Build paths are historical; see the [main README](../../../README.md) for current usage.
