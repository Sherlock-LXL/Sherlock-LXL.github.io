# v0.19 雨幕与留白

## 雨幕

- 用独立的随机三维采样替换原有取模排列，消除斜看、侧看时容易出现的整排雨滴。
- 每滴雨具有不同的速度、长度、轻微倾斜与明暗；同一雨滴的两个端点共享速度和循环相位，避免循环边界拉出长线。
- 雨雪继续在固定世界坐标中运动，不跟随玩家平移；摄影模式能够冻结。维持 7200 个雨滴和一次绘制，不增加逐帧 CPU 粒子循环。

## 空间避让

- 山路座椅按完整轮廓检查护栏、展台、碎片、道路及脚下坡度。现有两处座椅均没有满足留白条件的邻近位置，因此撤去，保留上山路线和护栏。
- 挡土矮墙增加周边物件及碎片避让检查；端帽也计入完整尺寸。
- 冬季雪垄移到家具、雪人、碎片与庭院装饰全部安排完成后生成。以实际尺寸检查空隙，远离道路和观看位置，雪垄之间也留出距离。
- 科研岛保留 28 处较薄、较小的积雪，露出高度约 6–14 厘米，不再用厚雪球包住低矮物件。
- 后排管道上的宽雪板改为贴合管道的薄弧形覆雪。
- 清除科研区碰到设备柜的岸边护栏，并为高管架留出树冠空间。

## 验证

- 50 项单元检查通过，包括雨滴空间相关性、多个角度的分布、完整装饰轮廓避让及后排设备护栏。
- 四区各三个角度、中央枢纽、港口与码头、五个方向的雨幕均已渲染检查；结果见 `artifacts/v19-clearance-*.png`、`artifacts/v19-rain-*.png` 和 `artifacts/clearance-v19.json`。
- 雪垄与全部碰撞物件、记忆底座及道路的完整轮廓检查通过；雨滴端点速度一致，移动观察位置不改变雨幕坐标，摄影冻结检查通过。
- 上山主路和 CNN 捷径双向行走、五级传送和跳跃着地通过；16 个 R 互动均从入口实际步行到达并成功触发。
- 晨昏与天气连续性、船体和 MV 屏幕多角度、风车旋转检查通过。

- 最终 EXE 的 63 个媒体与模型适配文件哈希一致；19 张封面和照片在首次启动、重复启动和刷新后均可解码，音乐、MV 播放跳转及两篇论文工作台通过。本轮未测试 Windows 物理 Esc，不计入通过项。

- 五张专辑和十四幅照片均实际步行到达，F 正确打开对应作品；抬头离开目标时取消交互提示。默认音乐、照片地点说明、八条记忆连线和碎片界面留白检查通过。
