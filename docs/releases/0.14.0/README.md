## 本人论文与参数工作台

原始文档只读，副本归档在 `asset-sources/research/`。`scripts/import-research.py` 从 Word 的 OMML 公式生成界面的原生 MathML；源文件名和公式编号保存在 `src/core/research-content.json`。数值逻辑位于 `shared/research-physics.mjs`，独立 Worker 计算，关闭工作台后释放线程与动画。

### 附壁气泡

来源：`D:\Programme\Bubble\Research\论文\Wall-Attached Bubble Growth in Electrolyte Solutions.docx`。

展示球冠体积系数、Henry 边界条件、Popov 扩散因子和式 (23) 半径增长方程。可调整远场过饱和度、气侧接触角、扩散系数、初始半径和表面张力，更新半径、增长率以及球冠动画。Popov 积分使用 Simpson 积分，增长方程使用 RK4；图中显示 60 分钟的变化。

演示固定温度 293.15 K、环境压力 101325 Pa、Henry 系数 1e-5 mol/(m³·Pa)，保持远场浓度恒定。默认半径 100 μm、接触角 90°、过饱和度 1.2、扩散系数 2e-9 m²/s、表面张力 72 mN/m。没有虚构盐浓度与物性的实验拟合关系。

### 声致发光

来源：`D:\Programme\Sonoluminescence\论文\论文-四改.docx`，标题为 Effects of salt concentration on single-bubble sonoluminescence。

展示论文的 Rayleigh–Plesset 方程（式 6）、绝热温度关系（式 10）、水活度与渗透系数关系（式 12）、蒸气压关系（式 13）。可调整声压、驱动频率、平衡半径、盐浓度、渗透系数与表面张力，更新三周期半径波形与振荡动画。

使用无量纲时间和半径、RK4 步长加倍误差估计、自适应步长解析快速坍缩。默认声压 1.15 bar、频率 26.5 kHz、平衡半径 4.5 μm。水的密度、黏度等作为演示常数；盐按 1:1 电解质计算，渗透系数手动输入，不冒充完整 Pitzer 参数拟合或实测发光强度。壁速超过 450 m/s 或半径过小时终止并显示模型适用范围提示，不延伸生成失真的曲线。

两篇稿件未提供本次可直接拟合的实验数据，所有默认值明确标为演示参数。数值工作台体现论文模型，不替代实验结论；场景里的气泡装置仍是便于观察的慢速展示动画。
