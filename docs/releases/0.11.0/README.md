# v0.11 · 星光与双展廊

本版在原有四季地形上整理动线与展览，不重置访客收藏或季节曲首演记录。

- 启动加载页固定到完整窗口中央，兼容窄窗口与错误重试页。
- AI 展台只保留编号、名称和简短技术说明；移除山径驿站副牌和第一人称悬浮重名标签。
- 九处记忆标记统一为六角石座、悬浮晶体与环绕星点。R 收集星光碎片，原记忆 ID 和中心星图保持连续。第一枚碎片移至礼物台地另一侧，与纸蝶分开。
- 移除所有跃石小径文字牌。道路纹理、护栏、植被和座椅使用共同的入口路线；夏、秋的桥头另设绕行曲线，避免穿过舞台或展廊。
- 科学山谷补充连续灰蓝铺装、厚雪堆、雪松和两位雪人。Bubble Laboratory 使用开放水槽，六个气泡错峰生成、缓慢上浮、水面破裂并扩散涟漪。声致发光使用球形透明腔体、两侧换能器和向中心传播的声波示意；同一中心气泡匀速膨胀、快速坍缩、短暂蓝白闪光后恢复。动画经过慢放，属于解释原理的示意，不是实验数据或物理求解。
- 夏岛增加低矮浅草；秋岛移除麦田与“形”雕塑，改为枫叶庭院、清晰前庭和左右两座开放式展廊。

## 专辑与照片

光影长廊以十四个画框展示全部已提供摄影，保持原作比例、标题和沉浸浏览。旋律展廊按原文件夹编号展示五张专辑：

1. Secret：3 首精选作品。
2. 星辰代我想你：1 首。
3. 近地轨道：3 首。
4. 二分之一星球：4 首。
5. 燕来有声：1 首，明确标注未名拾音团队项目。

专辑封面、十二首原格式人声音频、完整原始歌词及制作署名已接入。专辑按编号排序；曲目未提供原始曲序，因此标为精选曲目，不推定完整专辑曲序。选择曲目后手动播放，试听暂停场景背景音乐；切换专辑/曲目或关闭面板会停止上一首。既有伴奏轮播与一次性季节曲继续独立工作。春季纯音乐和团队原视频仍待提供。

原始 Pictures 文件未修改。`scripts/import-albums.py` 可重复导入专辑档案；`data/album-assets.json` 记录文件来源与 SHA256。封面生成展示用 WebP，原音频直接复制，歌词按原文本保留。

## 维护入口

- `shared/region-routes.mjs`：桥头到前庭与展台的共同路径。`data/world.json` 可用 `arrivalPath` 定义局部坐标折线，布景避让同步更新。
- 模块清单的 `wayfinding`：独立于完整说明的简洁实体标牌。
- 模块清单的 `albums`：编号、封面、归属、曲目与歌词。`src/core/album-gallery.ts` 自动呈现专辑 UI。
- `modules/photography/scene.ts` 与 `modules/personal-music/scene.ts`：共用开放展廊建筑。
- `modules/bubble-lab/scene.ts` 与 `modules/sonoluminescence/scene.ts`：独立科研场景；动画周期在 `shared/science-cycles.mjs`。动态子树与静态合批分开。

`tests/refinement-v11.test.mjs` 检查气泡周期、专辑顺序、十二份音频哈希、歌词和资产路径安全。`tests/refinement-v11.mjs` 检查两种窗口宽度的加载居中，三个平地岛屿的主路/支路双向实走，碎片与纸蝶间距、专辑切换、歌词、真实音频播放与字节范围响应，以及新展廊和实验装置截图。山路、CNN 捷径、跳跃、Esc 鼠标恢复与季节音乐另做既有回归。
