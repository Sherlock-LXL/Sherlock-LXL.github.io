# v0.12 星环与本地模型

## 世界布局

- 摄影、个人音乐两座展廊保持建筑与展品，转向桥头入口；前庭与支路同步调整，门楣分别标注光影长廊、旋律展廊。增加暖橙枫树、落叶地表层，强化秋岛。
- 未名拾音的舞台、顶棚、展板、终端与碰撞一起转向桥头，门牌安装在檐口。原视频仍待提供。
- AI 山脚门牌面向来路。移除超出山岸或悬落过高的挡土墙；CNN 捷径用贴地箭纹引导。
- 中心改为低矮水盘、星环和悬浮晶体组成的开放枢纽。记忆星图入口改成基座上方的星点连线。
- 调整天空蓝色渐变、海水青蓝层次与雾密度；原有柔和昼夜继续保留。

## 本地推理

五个模块的代码、权重、分词器及必要配置均复制到 `runtime/models/<id>`，没有修改原项目。Python 解释器与依赖复制到 `runtime/python`，不使用引用外部缓存的 venv 启动器。

XiangLM 使用 EXE 工作区已有的 `xianglm-200m-chat.pt`，大小 **801,296,040 字节**，为去除训练状态的推理导出；没有续训或修改模型精度。训练检查点不随包复制。其余四个模型使用原有推理权重。

Node 读取已打包适配器后，通过 Python `-I -B -X utf8 -u -c` 执行，工作目录为对应本地模型目录。Python 无需再次打开便携 EXE 的临时解压 worker 路径，修复双盲诗启动时找不到 worker 的错误。隔离模式、显式 UTF-8 和无缓冲输出兼容中文与流式生成。

诗歌逐字符、LLM 逐可解码 token 增量显示。实际采样产生后立即推送，最终结果与增量拼接一致；首字仍需等待模型加载。关闭面板或取消会终止推理。模型本身的重复、事实准确性等生成质量未在此版训练调整。

## 媒体与音乐

交付的 22 首音频统一为 MP3：七首伴奏、三首季节曲、十二首精选人声。原 MP3 保持原始字节，四份 WAV 交付副本转换为 320 kbps MP3，未修改 Pictures 原文件。旧 WAV 副本放在工程 `asset-sources/audio-wav`，不打入 EXE。照片与封面使用标准编号的 WebP；标题、专辑顺序、歌词和归属保留。

伴奏使用随机袋轮播，一轮遍历七首后重新洗牌，跨轮避免紧邻重复。修正结束事件与区域更新竞争导致重开旧曲的问题。季节首演以当前旅程为单位：同一窗口刷新或反复进出不会重播，新开应用窗口开始新旅程。进入没有新季节首演的区域继续伴奏；试听专辑时背景音乐让位。

## 交付与复现

完整目录：`build/XiangMeta-0.12.0/`。其中 EXE 打包场景、照片和音乐；`runtime` 存放推理依赖。移动时保留整个目录及相邻 `local.json`，无需原始仓库、Codex 缓存或另装 Python。Windows 版本限 x64。

源码的 `data/local.json`、独立 EXE 的 `build/local.json` 使用 `root: ".."`；完整版本目录使用 `root: "."`。相对路径均相对配置文件位置解析。

维护脚本：`scripts/localize-runtime.py` 从本机原资产位置只读复制推理依赖；`scripts/normalize-media.py` 标准化已有交付 WAV；媒体导入器也统一输出 MP3；`scripts/stage-portable.py` 复制本地 runtime 和已构建 EXE，形成可搬移目录。FFmpeg 位于工程 `runtime/tools/ffmpeg`，仅导入时使用，成品播放无需它。

布局扩展字段和流式协议详见 `docs/world-module-contract.md`。
