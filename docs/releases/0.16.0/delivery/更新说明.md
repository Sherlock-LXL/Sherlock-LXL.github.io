- 保留纸蝶来信、气泡许愿机、光谱风车、星音风铃；新增春日花灯、星轨仪、秋叶回旋、潮汐珠，共八个不同装置。新位置避开道路与现有家具，并实走验证。

- 十个侧栏图标改为同一 36 单位绘图网格、32 px 显示大小的彩色 SVG；窄窗口保持可见。

## 天气与模型细节

- 雨雪使用覆盖可玩群岛的固定世界坐标体积，落速与轻微飘动交给 GPU；移动、跳跃和抬头不会把整片雨雪一起拖走。
- 雨线两端共用同一个循环相位，避免回收粒子时突然拉出贯穿天空的长线。
- 阴天、雨天、雪天的昼夜颜色连续混合；日月阴影光源在贡献归零时交接，消除临界值硬切换。
- 摄影模式退出后平滑恢复原来时刻。天气仍采用 12 秒过渡，摄影模式暂停天气运动。
- 云朵增加轮廓分辨率、细微形变、错落云冠与柔和补光；云层扩展时小云瓣随整体缩放，避免散成一串小点。保持不透明深度遮挡，不重新引入阴天层闪现。
- 港口船体改为截顶船壳与相配的椭圆甲板，木纹接缝随船沿收边；增加护舷、系缆桩并调整缆绳端点。
- 《燕来有声》封面缩入舞台实体背板的屏框内，移除占位播放立体图形；侧面与背面由实体结构承接。

本机 1280×800 浏览器短时抽样约 45–46 FPS（同期在校验便携运行时文件），记录见 artifacts/performance-v0.16-final.json；不是稳定 60 FPS 的结论，不能代表实际 EXE 在所有设备上的帧率。固定雨雪只覆盖当前可玩群岛；远景岛屿尚未开放。浏览器自动化可验证界面关闭后的鼠标锁定逻辑；物理 Esc 在 Windows 前台输入受限环境中的验证仍不等同于真人键盘验收。
