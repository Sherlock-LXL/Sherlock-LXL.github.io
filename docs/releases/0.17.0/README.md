# v0.17 群岛拾趣

## 界面与照片

- 展台底部操作栏延伸至面板两边，使用与面板相同的不透明背景，消除左右色彩断层。
- 摄影展廊改为保持原始比例的多列瀑布流；窄窗口切换单列。横幅和竖幅不再被等高网格拉出大块空白，保留逐张沉浸观看。
- 滚动条、滚动槽与 Windows 标题栏统一为深青色。标题栏保留拖动区域和系统窗口按钮，内容避开顶部 32 像素。
- 精简返回、工作台、MV、模型运行和碎片收集按钮，底部操作文字保持单行。
- 成长档案只保留项目经历、研究过程与创作故事，移除 README、实现说明和提示性免责声明。

## 世界修整

- 猫咪补齐对称的两条前腿、前脚掌和后脚掌，尾巴移向身体后侧。
- 移除山路旁容易横跨坡面的小型硬质土槽；花朵分别贴地种植，陡坡与山顶停止布置这类路边花簇。保留道路、平台、护栏和春季整体风格。

## 每区四个 R 互动

保留八个已有互动及其收藏 ID，新增八个小型装置。新增装置缩小至标准基座的 68%，安放在路旁可达空地，避开家具、碎片和工作台。所有装置均无文字展牌，以光点提示，走近后显示名称与 R 操作。

| 区域 | 保留 | 新增 |
| --- | --- | --- |
| AI 山脉 | 纸蝶来信、春日花灯 | 词语织机、云间铃 |
| 科学山谷 | 气泡许愿机、星轨仪 | 掌心雪境、雪原钟摆 |
| 个人博物馆 | 光谱风车、秋叶回旋 | 秋色万花镜、袖珍唱片机 |
| 未名拾音 | 星音风铃、潮汐珠 | 藏星贝壳、微光灯塔 |

不同装置分别呈现词块编织、铃声摇摆、球内飘雪、双端钟摆、彩瓣旋转、唱片与短音符、贝壳开合和旋转航灯。雪与唱片以累积相位运动，触发时平滑加速，避免运行时间越长越容易突跳。
