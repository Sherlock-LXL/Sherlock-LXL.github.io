Added 768×960 planar reflection fading at 30–42 m, unified vector star-map coordinates and buttons, and moved the spawn southeast of the hub.

### Validation

Fifty automated checks and three mirror views passed; star/line alignment error was below 0.02 px. Sixty-three files matched; physical Esc was not retested.
