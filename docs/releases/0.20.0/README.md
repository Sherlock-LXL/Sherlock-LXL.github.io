# v0.20 · 镜面与对齐

## 更新

- 镜子房间改为实际世界的平面反射，观察位置变化时反射视角同步变化；保留厚实边框与背板。
- 镜面采用 768 × 960 离屏图像和抗锯齿；画面外不渲染反射，30–42 米平滑淡出，42 米外停止反射绘制。反射不重新计算阴影。
- AI 山脉入口门牌缩短立柱，补上底托；所有产品展台的支柱一并调整，避免从倾斜牌面下方穿出。
- 记忆星图改用对称矢量星形，编号独立排列，星形中心与顺序连线端点共用同一坐标系。
- 初始出生点移到中央枢纽东南侧的开阔处，面向中心；各区域传送位置保持原有逻辑。
- 抵达展台、收藏、返回采用统一矢量图标；收藏同时保留选中外观和无障碍状态。

## 验证

- 50 项自动检查通过，生产构建通过。
- 中央出生点可行走，展台支柱与倾斜牌面留有间距。
- 左、中、右三个镜面观察角度的虚拟相机位置验证通过，远距离淡出通过；已检查真实世界截图。
- 1500 / 760 像素宽度下，星形中心与连线端点误差小于 0.02 像素；收藏切换和按钮布局通过。
- 主山路与 CNN 捷径双向通行、五个展台传送 / F 交互 / 跳跃落地通过。
- 开发与便携版共十份模型配置、58 个本地媒体地址、两份论文原稿及模型哈希通过；63 个打包媒体与 worker 文件和源文件一致。
- 最终 EXE 在首次启动、第二次启动和刷新后均可解码 19 张照片 / 封面；专辑播放、MV 播放与跳转、两篇论文参数曲线、港口和团队档案通过。本轮未做物理键盘 Esc 的桌面重测。
- 测试截图和报告保存在 `artifacts/current/`；浏览器检查采用软件渲染，不能作为实际显卡帧率承诺。
