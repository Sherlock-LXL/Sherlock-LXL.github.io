- 8 组核心测试：全部清单、输入验证、新增模块发现、坏模块隔离、路径限制、导航拓扑、示意曲线、HTTP 网关、并发/取消、worker 超时与 UTF-8 响应（部分场景在同一组内）。

## 真实模型冒烟测试

全部通过模块自己的 worker 调用外部原项目与原权重，未使用模拟结果。测试运行在 CPU，时延是单次观测，不是性能基准。

| 模块 | 观察 | 单次耗时 |
|---|---|---:|
| XiangLM | 默认问候得到非空中文回复 | 10.91 秒 |
| 双盲诗 | 生成两段非空文本，独立采样 | 3.81 秒 |
| 表情识别 | 原项目 sample_01.jpg，三模型输出 sad / neutral / fear 概率 | 10.89 秒 |
| 礼物预测 | 默认七项 0.7、书籍文创，得分 8.38 / 10 | 0.31 秒 |
| 猫咪识别 | 原测试集棉花糖照片，完成检测/裁切/三模型集成，首选棉花糖 96.3% | 8.93 秒 |

这些仅确认推理集成可用，不能代替模型准确率评测。未将测试输入发布为展览素材。

## 本轮验证中修复的问题

- Electron 随机端口导致存档 origin 改变：固定为 4319，并增加单实例锁。
- 面板关闭后键盘焦点不稳定：明确恢复世界 canvas 的焦点。
- 快速重复请求摄像头：请求权限期间禁用按钮；晚到的授权在面板已关闭时立即释放。
- 子进程 UTF-8 输出可能跨 chunk 分割：使用流式 UTF-8 解码。
- 世界区域数量和 Agent 入口改为读取配置；不把新增项目依赖写进核心。
