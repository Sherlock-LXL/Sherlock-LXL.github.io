# v0.21 · 山坡与接缝

- 世界向导球体上移，缩小光核并增加球面细分；中央装置采用不同半径的环带，避免球体与下方结构相交。
- 四座桥两侧栏杆与灯线根据圆环侧边交点收口，圆环前预留 18 厘米间距，桥面仍保留连续连接。
- 山体展台边缘扩大坡面过渡，折返路外侧的高程改为邻近路段平滑融合，保留道路中心和展台基础高度。
- 山墙采用低对比细纹，取消成片斑点；砖纹在陡坡上淡出，避免从山路拉伸到竖直岩面。
- 栏杆按完整跨度及厚度检查地面净空，无法跨越的凸坡处断开成段；支柱按周围地面最高点确定扶手高度，柱脚延伸至土中。

截图与本轮验证记录位于 `artifacts/current/`。运行 `build/XiangMeta-0.21.0/XiangMeta-0.21.0-x64.exe`，移动程序时复制整个版本目录。
