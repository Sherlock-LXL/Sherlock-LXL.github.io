# XiangMeta 0.21.0 · 山坡与接缝 / Slopes and seams

[中文](#中文) · [English](#english)

## 中文

调整引导星、桥栏与圆环接头，平滑山路外侧高度，改善岩壁纹理并按真实地形设置护栏。

### 验证

53 项自动检查通过，35 段栏杆最低净空至少 0.333 米；路线、十六互动与63 个打包文件通过，本轮未重测物理 Esc。

[技术与验收记录](notes.md)保留当时的操作、参数、指标、SHA 和验证范围。旧构建路径仅作历史记录；当前运行方式见[主 README](../../../README.md)。

## English

Adjusted the guide star and bridge/ring joins, smoothed outer road heights, refined cliff texture and fitted rails to actual terrain.

### Validation

Fifty-three automated checks passed; 35 rail runs had at least 0.333 m lower-bar clearance. Routes, sixteen interactions and 63 packaged files passed; physical Esc was not retested.

[Technical and validation notes](notes.md) retain the original controls, parameters, metrics, hashes and test scope. Build paths are historical; see the [main README](../../../README.md) for current usage.
