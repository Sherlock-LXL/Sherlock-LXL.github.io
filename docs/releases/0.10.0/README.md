## 摄影

14 幅照片已接入摄影馆的真实画框、展品列表和沉浸浏览。保留原文件名中的作品标题，不编造拍摄日期或故事。生成 2400 像素以内的 WebP 展示图及 640 像素缩略图，保留长宽比、纠正 EXIF 方向，导出时不携带原 EXIF。28 张交付图片共约 8.1 MB；原始照片保持不变。

## 音乐规则

进入世界后点击右上角 ♪ 开启声音。背景音乐包含 7 首流行歌伴奏及 3 首季节纯音乐，源音频保持原格式与音质。

- 普通场景使用随机轮播袋：一轮内每首伴奏播放一次，轮次之间避免紧接着重复同一首。
- 夏、秋、冬的季节曲在首次进入相应岛屿且允许出声时自动播放，单曲不循环。
- 只有实际成功开始播放才记录已首演。快速进出、后续回访、刷新或重开同一来源的世界，不会自动从头再播。
- 若另一个尚未首演的季节被触发，会平滑切换；此前已经开始过的曲目仍记为首演过。回到已首演的岛屿不会打断当前曲目。曲终回到伴奏电台。
- 静音会暂停，恢复声音延续当前位置；静音期间进入岛屿不消耗它的首演机会。
- 日后加入的人声/视频展品在手动播放时暂停背景音乐，停止试听后恢复，避免叠播。

首演记录使用 `xiangmeta:seasonal-music:v1`，与访客收藏分开，按稳定 track id 持久化。浏览器预览与 EXE 使用不同本地来源，各自维护记录。更换季节作品时给新作品使用新 id，不必清空旧收藏。

## 留空的展位

按最新要求，个人音乐馆保留给之后提供的有人声作品，不上架这些纯音乐和伴奏。春季纯音乐创作中；《燕来有声》原视频未加入，品牌区继续保留项目档案及已有发行链接。

## 维护

- 区域在 `data/world.json` 设置可选的 `season`，布景与原有建筑模块分离。
- 世界音乐清单位于 `public/assets/audio/manifest.json`，音频由独立模块 assets 托管，不复制外部 AI 仓库。
- `shared/music-programme.mjs` 管理轮播和首演决策；`src/audio/audio.ts` 处理播放、淡入淡出、暂停与恢复。
- 后端以流式字节范围响应提供音频，支持较大 WAV 文件的播放和拖动定位，避免每次请求将整首音频读入内存。
- `scripts/import-personal-assets.py` 记录本次导入流程，只写项目内的交付副本；不会修改 Pictures 中的原文件，也不会覆盖未来个人音乐馆的人声展品。

## 验证与成品

通过 32 项单元测试；浏览器验证真实 MP3/WAV 播放、WAV 定位至曲尾并回到伴奏、频繁出入去重、静音恢复、刷新后的首演记录、媒体互斥及 14 张原作浏览。山路、CNN 捷径、跳跃、记忆星图、模型交互和昼夜也完成回归。四季截图保存在 `artifacts/season-*.png`。

Edge 无头模式、1280×800、120 帧抽样：近景约 65.6 FPS（p95 17.5 ms），全景约 78.8 FPS（p95 16.5 ms），平均绘制调用约 176 / 492。记录见 `artifacts/performance-v0.10.json`；这是当前测试环境的一次抽样，设备、负载和镜头位置会影响实际帧率。

Windows 成品为 `build/XiangMeta-0.10.0-x64.exe`，继续保留 `local.json` 与外部模型环境。旧版 EXE 保留。

已通过真实 Windows 便携版启动测试，包括随包《星河》实际播放、摄影清单、人声展位留空、模型调用、跳跃、摄影与 Esc 恢复鼠标锁定。测试后恢复原访客存档及首演记录。10 首音频的原文件、项目副本和解包资源 SHA256 一致。
