# v0.4 · 世界里的小惊喜

## 字体统一

双盲诗产品输出取消独立楷体、大字号和额外行距，使用与 XiangLM 等产品相同的界面字体、14px 字号和 2.1 行高；保留原始诗句换行。窄屏沿用统一的 13px 输出样式。

## 四座趣味装置

| 区域 | 装置 | 靠近按 R |
|---|---|---|
| AI 山脉 | 纸蝶来信 | 从打开的书页唤起一群折纸蝴蝶 |
| 科学山谷 | 气泡许愿机 | 释放一簇轻盈上升的气泡 |
| 个人博物馆 | 光谱风车 | 让十片马卡龙色叶片加速旋转 |
| 未名拾音 | 星音风铃 | 摇动风铃；开启声音后播放一段五声音阶 |

首批装置位于各区入口右侧附近。装置正面朝向到达庭院，底座有文字铭牌。右上角 ✧ 打开「旅行印记」，查看发现记录和区域入口。重复体验不会重复计数，老版本的收藏和探索记录继续保留。

R 仅在第一人称、产品面板关闭且装置距离 2.8 米以内时生效。产品展台继续使用 F，其附近优先显示 F 提示。装置设 1.6 秒触发间隔；动画逐渐平息。减少动态效果的系统设置会停用装饰动画，仍可收集印记。风铃默认静音，音量使用交互音轨设置，关闭声音会停止已安排的风铃音符。

这些是装饰性互动，纸蝶不冒充 AI 生成，气泡动画不是科研求解器。双盲诗和科研产品原来的独立入口保持可用。

## 近景精细度

- 塔楼增加窗格、阳台细栏杆与立柱；诗园增加攀缘植物、花点和矮凳。
- 猫咪增加胡须、项圈和小铃；花坛增加分瓣花朵、花心、叶片与铭牌。
- 科学山谷加入仪表、管线与屋顶望远镜；博物馆提升雕塑曲面细度并增加编号牌。
- 音乐区域增加钢琴黑键、琴盖和谱架，以及黑胶唱机、唱片沟槽与唱臂。
- 保留 v0.3 的单层地面、马卡龙配色和 5.2 / 8.5 米每秒移动速度。

花坛使用实例化绘制；装置固定数量复用几何体，无逐帧新建粒子、无新增后处理库或网络依赖。

## 扩展方式

装置由 `data/world.json` 中可选的 `region.discovery` 定义，包含 kind、title、action、description 和区域内 position。新区域可复用任一装置，只需增加配置。新装置行为在 `src/world/discoveries.ts` 的通用构建与动画层注册，不为 AI 项目写特殊分支。提示、印记和存储由统一事件连接。

## 验证

- TypeScript / Vite 构建、12 项核心测试通过。
- `tests/discoveries.mjs`：双盲诗与 XiangLM 输出字体、字号、行高一致，真实诗歌推理成功；四个装置可步行抵达；R 距离限制、面板/地图禁用、重复收集、刷新持久化、五个风铃音符、静音与减少动态效果路径均通过。
- `tests/movement.mjs`：实测行走 5.23 米/秒、加速 8.50 米/秒，终端碰撞与 F 交互通过，保留移动地面采样。这是本机短时观测，不是跨硬件性能基准。
- `tests/browser.mjs`：十个原有展台传送与 F 工作台、地图、收藏、导览、科研示意交互、摄像头轨道释放、真实礼物模型及窄屏布局回归通过，无未捕获页面错误。
