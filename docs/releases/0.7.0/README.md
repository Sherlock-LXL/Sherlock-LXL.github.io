# v0.7 · 成长与记忆

本轮围绕成长路径、记忆星图和项目联系展开，保留第一人称、跳跃、快速传送与 F 产品工作台。延续马卡龙配色和柔和昼夜，以少量动态细节增加各区辨识度。

## 新的探索方式

- **五站成长路径**：张量与网络 → CNN 与真实数据 → RNN 与序列 → Token 与 Attention → XiangLM。金色路标与小型基座沿现有可行走区域串联，左侧可以追踪或抵达。这是概念路线，不是精确履历时间线。
- **八段记忆**：在各区寻找发光标记，靠近按 R 读取项目经历。中央导览亭上方的星图随探索点亮，右上角 ✶ 可查看收藏；重启保留进度，旧版存档兼容。
- **项目联系**：诗园连向 XiangLM，摄影展廊与猫咪识别相互连接。关联卡片支持直接抵达，保留个人创作与团队品牌的区别。
- **摄影模式**：按 P，自由移动取景，WASD 平移、Q/E 升降、拖动环顾，调整 30°～90° 视野和晨昼暮夜。世界动画与自然时钟暂停，退出恢复原位置、视角和时间。可导出纯照片或带地点与世界时刻的 PNG 明信片。
- **沉浸看图**：摄影作品卡片新增沉浸观看和前后切换。现有程序化策展习作明确标注为占位，等待本人原作替换。

## 世界细节

XiangLM 塔的数据流、诗园萤火与工作室柔光随昼夜改变；科研区透明液体中有缓慢生成、上浮、消散的气泡，声致发光只有局部柔和光脉冲。动画是展览示意，不代替实验测量或物理求解。

未名拾音以《燕来有声》为主题增加舞台海报，保留正式 MV 外链。远处点缀机器人岛、研究院和城市剪影，目前不开放进入。没有虚构歌词、制作名单、论文、实习或个人里程碑日期。

## 长期扩展

[World Module Contract v1](../../world-module-contract.md) 已落地。一个模块可以自带 manifest、assets、scene.ts、interactions.ts 和可选 region.json；地图、传送、输入界面、记忆、成长路线、关联和聊天入口按契约注册。`modules/weiming/scene.ts` 是已运行的示例。

模型源仓库与权重仍独立，公开 catalog.tools 从真实 runtime / interface 生成。音频可由模块声明，支持 1.2 秒淡入淡出；无素材时不阻塞世界，也不假装播放不存在的原作。

## 验证

24 项单元和网关测试覆盖契约、模型输入、取消、导航、跳跃、昼夜与存档相关数据。浏览器回归检查十个 F 工作台、真实推荐推理、摄像头关闭、地图与传送；新增 living-world 验证八段记忆均可抵达、星图保存、可行走成长路线、摄影相机隔离/时间恢复/PNG 导出及展廊关联。

最终 EXE 的原生锁鼠自动化出现过一次超时；增加错误记录后重跑通过，未据此声称所有焦点切换情形都已消除。

Windows 便携版已用实际可见窗口验证：原生 Esc 鼠标恢复、跳跃落地、R 装置、八颗记忆星、摄影模式、F 工作台和真实推荐模型，完成后恢复原访客存档。

摄影回归还覆盖面板延迟 close 事件不会解除角色暂停，以及滑杆拥有焦点时 Esc 仍可退出摄影。

视觉细节继续采用静态合批、共享材质和 Points。性能数据见 `artifacts/performance-v0.7.json`，为本机固定视口的短时样本。最终记录约行走 53 FPS、总览 39 FPS，平均绘制调用约 135 / 504（含定期阴影通道）。仍存在帧率波动，未宣称稳定 60 FPS；帧率随分辨率、GPU、相机位置和后台负载变化。操作指南保留降低渲染质量开关。
