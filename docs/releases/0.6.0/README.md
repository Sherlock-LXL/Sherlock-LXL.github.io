# XiangMeta 0.6.0 · 昼夜与相机 / Daylight and cameras

[中文](#中文) · [English](#english)

## 中文

隔离步行与地图相机，改善锁鼠恢复；增加 16 分钟昼夜周期、连续纸蝶动画与静态合批。

### 验证

20 项核心测试通过。可见 Windows 窗口验证原生 Esc；同机绘制调用从 1,889 / 3,304 降至约 87 / 403。

[技术与验收记录](notes.md)保留当时的操作、参数、指标、SHA 和验证范围。旧构建路径仅作历史记录；当前运行方式见[主 README](../../../README.md)。

## English

Separated walking and atlas cameras, improved pointer-lock recovery and added a 16-minute day cycle, continuous butterfly animation and static batching.

### Validation

Twenty core tests passed. Native Esc was checked in a visible Windows window; same-machine draw calls fell from 1,889 / 3,304 to about 87 / 403.

[Technical and validation notes](notes.md) retain the original controls, parameters, metrics, hashes and test scope. Build paths are historical; see the [main README](../../../README.md) for current usage.
