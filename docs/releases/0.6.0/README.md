# v0.6 · 海岛时光

## 操作与场景

- 第一人称使用独立相机，地图惯性与事件不再影响它。鼠标锁定切换会丢弃首次重定位采样，并过滤非有限值或异常巨大的单次位移。
- 关闭产品、索引或向导面板后，在第一人称中请求原生鼠标锁定；地图中保持普通鼠标。按第二次 Esc 可以释放鼠标使用菜单。浏览器若拒绝锁定，现有「点击进入环顾」入口仍可用。
- 纸蝶使用连续的能量包络与累积翅膀相位。触发或再次触发只改变目标，保留当前位置与动画相位，缓慢升起、回落。尊重系统减少动态效果设置。
- 中心使用四面导览亭、罗盘刻度与悬浮向导。所有程序化标牌都有实体边框和正确朝向的背面文字。
- 茶杯使用旋转截面构建杯壁和底部，弧形把手两端接入杯壁，增加杯碟和茶面。
- 岸边栏杆与树木、路灯分属不同径向带，入口、展品和后方建筑保留空隙。
- 海面加入低幅波纹、柔和岸线与四处远岛轮廓。
- 日月在相反方向沿同一轨道转动，06:00 日出/月落，18:00 日落/月升。天空、海面、雾、主光、环境光与灯带连续变化；白天低对比，夜晚仍有可读的月光与环境光。右上角时钟支持预览或暂停流转，默认 16 分钟一昼夜。

## 渲染与可维护性

`src/world/optimizer.ts` 在每个区域、展品和桥梁内部合并材质一致的静态几何，保留区域剔除边界。透明物体、实例化对象、骨骼动画及 `pulse` 动态子树保持独立；未来动态子树也可以标记 `userData.dynamic`。外部 GLB 继续保留动画生命周期。

阴影使用一盏主方向光，每 100 毫秒刷新一次，日月交替时在地平线附近降低强度。默认像素比上限 1.35，支持关闭阴影的低画质模式；无需为每个路灯新增点光源。标牌投影更新上限 30 Hz，画布尺寸缓存，避免逐个标签读写布局。

环境逻辑独立在 `src/world/environment.ts`，昼夜权重与纸蝶包络在 `shared/atmosphere.mjs`，岸边布置在 `shared/shore-layout.mjs`。新增区域的海岸和布置从区域清单生成；不依赖项目 ID。

## 验证

- 20 个核心测试涵盖既有模块契约、推理取消、移动与跳跃，以及新增昼夜连续性、纸蝶包络和栏杆间距。
- `refinement.mjs` 使用真实浏览器验证 Esc / 关闭按钮恢复原生鼠标锁定、地图惯性后连续行走无坐标回退、日出/白天/日落/夜晚及地图面板行为。
- `scene-fixtures.mjs` 渲染导览亭四面、标牌正反面、杯子细节及海上天体，检查真实纸蝶变换连续 600 帧，并再次触发动画。
- 原有浏览器、真实诗歌、礼物模型、跳跃落地及便携 EXE 验证均通过。`portable.mjs --visible` 在真实桌面窗口验证了 Esc 原生鼠标恢复，测试后自动关闭窗口并恢复原有探索记录；隐藏窗口无法获取操作系统鼠标锁定。
- `artifacts/performance-before.json` 与 `performance-after.json` 为同机、1280×800、无头 Edge 的采样。第一人称平均绘制调用由 1,889 降至约 87；地图由 3,304 降至约 403。绘制调用包括按间隔刷新的阴影；它是渲染开销指标，不等同于任意设备的帧率保证。

此次稳定性测试未复现坐标回退；相机隔离和鼠标异常采样处理针对代码中可能引起镜头突变的路径。长时间硬件实际使用仍可补充诊断，`?inspect=1` 可提供只读的位置、相机、渲染统计快照。
