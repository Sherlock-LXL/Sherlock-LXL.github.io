# XiangMeta 0.3.0 · 配色与行走 / Palette and movement

[中文](#中文) · [English](#english)

## 中文

采用马卡龙配色与单层地表铺装，修复桥面深度冲突；行走与加速设为 5.2 / 8.5 米每秒。

### 验证

11 项核心测试、十个展台回归与 Windows 成品启动通过。实测速度为 5.21 / 8.51 米每秒。

[技术与验收记录](notes.md)保留当时的操作、参数、指标、SHA 和验证范围。旧构建路径仅作历史记录；当前运行方式见[主 README](../../../README.md)。

## English

Introduced a pastel palette and single-surface paving, fixed bridge depth conflicts and set walking/running to 5.2 / 8.5 m/s.

### Validation

Eleven core tests, ten-station regression and Windows launch checks passed. Observed speeds were 5.21 / 8.51 m/s.

[Technical and validation notes](notes.md) retain the original controls, parameters, metrics, hashes and test scope. Build paths are historical; see the [main README](../../../README.md) for current usage.
