# v0.3 · 马卡龙世界与行走优化

## 操作变化

普通行走由 3.2 提高至 5.2 米/秒，Shift 加速由 6 提高至 8.5 米/秒。保持 1.7 米第一人称眼高、原有视野、鼠标环顾、区域/展台传送和靠近按 F 打开产品工作台。

移动仍使用最长 0.12 米的碰撞子步。单帧时间上限由 50 调整为 100 毫秒，减少低于 20 帧时人为减慢行走的问题，同时避免长时间卡顿后大幅跳跃。

## 地面修复

- 原桥面和岛面顶端均为 y=0，导致深度冲突；现在桥仅覆盖岛间空隙，两端收进岛缘，桥面低于岛面 4 厘米。
- 原来的多条道路、边线和虚线分别是叠放的几何面，路口会互相覆盖。现在 `terrain.ts` 将曲线步道、展品广场和铺砖纹理绘制到单张地表贴图，每座岛只有一个可见地面表层。
- 地表使用 mipmap 和各向异性过滤；贴图接缝低对比，远处不依赖细小高亮网格。
- 博物馆七块重叠屋檐改为连续屋檐；调整阴影偏移，减少表面的自阴影条纹。

不使用逐帧修改 renderOrder 或禁用全部深度测试来掩盖问题。

## 视觉变化

- 薄荷绿 AI 山脉、婴儿蓝科学山谷、蜜桃色个人博物馆、薰衣草色未名拾音，搭配奶油色铺砖和浅青色水面。
- 圆角陶瓷质感建筑、三簇式树冠、圆润山丘、球形庭院灯、粉色花簇与带细节的猫咪雕像。
- 柔和晴空、奶油云朵、低金属度材质，保留日光方向与地面投影。
- 云朵使用实例化绘制；树冠复用几何体，未加入新的后处理依赖。
- 终端改用浅色面板与深色文字，总览区域标签加强浅色场景中的可读性。

模型和草木仍是可替换的程序化展览资产，未引入新素材要求，也未改动外部 AI 项目。

## 本机验证

- TypeScript / Vite 生产构建与 11 项核心测试通过。
- Edge 浏览器完成十个展台的传送、F 工作台、收藏、相机轨道清理、科研示意交互和真实礼物模型调用，无未捕获页面错误。
- `tests/movement.mjs` 实测普通速度 5.21 米/秒、加速 8.51 米/秒；加速持续接近终端未穿透，停止后 F 交互正常。坐标保留一位小数，因此短时间实测有舍入误差。
- 检查四个连续移动位置的地面截图，以及四个区域和俯瞰图。原来的叠面闪块未在这些采样中出现；这不是全 GPU / 驱动兼容性保证。
- 最终便携 EXE 实际启动验证通过：十个展品、默认第一人称、展台传送、F 产品工作台、同目录配置和真实礼物模型调用。成品为 86,612,462 字节，校验值见 `build/SHA256-0.3.0.txt`。

复核画面与实测数据在 `artifacts/`；便携包位于 `build/XiangMeta-0.3.0-x64.exe`。
