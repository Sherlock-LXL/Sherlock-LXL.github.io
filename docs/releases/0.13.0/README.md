# XiangMeta 0.13.0 · 风与回声 / Wind and echoes

[中文](#中文) · [English](#english)

## 中文

默认启用声音，改进 Esc 恢复；19 件摄影与专辑有独立 F 入口，天气以 24 秒连续切换。

### 验证

39 项单元测试与十九件作品实走通过；最终可见 Windows 检查包含停留 6.5 秒后的 Esc 恢复及流式模型。

[技术与验收记录](notes.md)保留当时的操作、参数、指标、SHA 和验证范围。旧构建路径仅作历史记录；当前运行方式见[主 README](../../../README.md)。

## English

Enabled sound by default, improved Esc recovery, gave 19 photographs/albums their own F targets and added 24-second weather transitions.

### Validation

Thirty-nine unit tests and walking access to all 19 works passed. Visible Windows checks included Esc after a 6.5-second panel stay and streaming models.

[Technical and validation notes](notes.md) retain the original controls, parameters, metrics, hashes and test scope. Build paths are historical; see the [main README](../../../README.md) for current usage.
