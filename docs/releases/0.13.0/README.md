# v0.13 风与回声

## 操作与界面

桌面进入世界默认播放音乐，音符按钮可以关闭。浏览器预览也默认开启，但浏览器若限制自动播放，会在首次点击世界或按键后开始。季节曲仍按旅程去重，七首伴奏继续随机轮播，个人专辑试听时背景乐让位。

音符、关闭按钮使用 SVG，静音斜杠按按钮中心定位。记忆详情保留底部空白和按钮间距。星图按显示编号连接全部记忆，使用有间隔的折返布局，实体星图与界面采用同一排列。未来岛屿说明统一为中文。

Esc 关闭界面后恢复第一人称环顾。浏览器在 keydown 阻止默认关窗、keyup 恢复鼠标锁定；桌面通过隔离 preload 只报告面板/摄影模式是否打开，由主进程将物理 Esc 转为用户动作，避免停留较久后因激活状态过期而无法重新锁定。没有向页面暴露 Node 或文件系统。摄影模式退出也恢复环顾；地图模式保持地图。

## 秋岛与作品交互

两座展廊由约 9.6×12.8 米缩小为 7.8×10.6 米，占地减少约三分之一，入口仍朝向来路。展馆之间留出庭院，桥头、前庭与支路重新衔接；座椅也缩窄，保留沿墙观看空间。

音乐展廊从入口看：左墙为第 1 张专辑，正面依次为第 2、3、4 张，右墙为第 5 张。五张专辑与十四幅摄影分别具有独立 F 交互点：打开指定专辑的工作台或指定照片的沉浸观看。转角处按观看位置选择作品，避免被另一侧更近的墙面抢占。

照片把原文件名中的地点与作品名分开，例如“深圳-盛夏”显示为“盛夏”，小字为“拍摄于 深圳”。媒体、封面、曲目、歌词及文件内容保留；导入脚本也使用新的命名规则。

## 布景与天气

气泡许愿机、星音风铃周围预留 3.1 米灯具与植被避让，雪人面向道路。纸蝶移到第一层台地的平坦侧边，基座一圈的高差已校验。山壁替换为无横向条纹的砂岩/苔色纹理，树木只放在起伏较小的区域；夏岛改为暖浅金沙滩。

天气有晴天、多云、阴天、雨天、雪天。初始晴天，自动模式每约 2–4 分钟随机选择不同天气，转换用 24 秒缓慢插值；中途修改也从当前状态继续。云团缓慢漂移，阴晴影响天色、雾、日月可见度与照明，雨滴和雪花随强度渐入渐出。右上角时光设置可选天气或恢复自动，摄影模式暂停天气、云和降水运动。

云、雨、雪使用实例化或共享粒子绘制，最多增加三类共享绘制，不逐颗创建独立对象；系统“减少动态效果”时停止云运动并隐藏雨雪。没有增加全屏后处理。
