XiangMeta 0.13.0

双击 XiangMeta-0.13.0-x64.exe 启动。
请移动或复制整个 XiangMeta-0.13.0 文件夹，保留 local.json 和 runtime。
EXE 包含世界、摄影与音乐，runtime 包含五个模型和独立 Python 环境。
不需要原始项目、Codex 缓存或另行安装 Python。首次模型加载需要几秒。
生成结果逐步显示；关闭界面会取消当前推理。

WASD 移动，鼠标转向，空格跳跃，F 使用展品，R 收集，P 摄影。
Esc 关闭工作台后直接恢复鼠标环顾。靠近专辑或照片按 F，打开当前作品。
右上角时光设置可选择晴天、多云、阴天、雨天、雪天，或自动轮换；天气缓慢过渡。
进入世界后默认开启音乐，点击音符可以关闭。七首伴奏自动换曲；季节曲每次旅程首演一次。
同一次旅程反复进出或刷新不会重播，重新开启应用开始新的旅程。
收藏与个人进度保存在当前 Windows 用户的应用数据中。
春季纯音乐和《燕来有声》原视频仍待补充。
