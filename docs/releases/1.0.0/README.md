# XiangMeta 1.0.0 · 正式版 / Stable release

[中文](#中文) · [English](#english)

## 中文

首个正式版包含四季世界、科研与模型工作台、原作展廊、记忆、摄影和港口。24 份音轨按约 -14 LUFS 校准，默认媒体音量 95%；护栏增至 54 段。

### 验证

前一轮 55 项检查、100 个面板状态、五模型及原生 Windows Esc 通过。最后定稿微调仅执行类型检查和构建，未重复完整验收；SHA 绑定实际被测文件。

[技术与验收记录](notes.md)保留当时的操作、参数、指标、SHA 和验证范围。旧构建路径仅作历史记录；当前运行方式见[主 README](../../../README.md)。

## English

The first stable release includes the seasonal world, research/model workbenches, original-work galleries, memories, photography and harbour. Twenty-four tracks are calibrated to about -14 LUFS with 95% default media volume; rails expanded to 54 runs.

### Validation

The preceding round passed 55 checks, 100 panel states, five models and native Windows Esc. Final small adjustments received type/build checks only; full regression was not repeated and hashes identify the actual tested files.

[Technical and validation notes](notes.md) retain the original controls, parameters, metrics, hashes and test scope. Build paths are historical; see the [main README](../../../README.md) for current usage.
