# XiangMeta 1.0.0

首个正式成品：四季岛屿、AI 成长山径、科研工作台、个人摄影与音乐展廊、未名拾音、记忆星图和海风港口。

## 本轮完善

- 测量全部 24 份音乐与 MV 音轨的响度。播放时按约 -14 LUFS 校准，音乐、专辑和 MV 默认音量统一为 95%，增加峰值保护。原始录音、视频与标准化媒体文件均不重编码。
- 开关提示音由 0.045 调低至 0.02，交互音由 0.13 提升至 0.22；环境音预设提升至 0.65。切歌、展品播放与退出后的背景音乐继续保留渐变。
- 声致发光的长公式按完整项分行展示，保留论文公式内容，改善窄面板阅读。
- 清除未使用的导入、材质和字段，开启构建时的未使用代码检查；保留模块契约、模型适配器和有效回归测试。
- 使用 XiangMeta 八向星芒图标，统一成品版本号为 1.0.0。
- 同版收尾补齐港口坡道两侧末端立柱。山径护栏依据邻近路面高度延长立柱，提高横杆，并缩短立柱间距，连续护栏由 35 段增至 54 段；展台入口和捷径开口保持畅通。
- 仅调整渲染预算：像素倍率上限 1.2、1024 阴影每秒更新约 3 次、512×640 镜面在 12–20 米渐隐。保留建筑、植被和区域规模。

## 最后定稿微调

- 春日花灯向旁边平地移动约 1.4 米，避开山坡与底座交叠。
- AI 山脉入口标牌保留原位置与朝向，按底座覆盖范围的坡顶高度抬正，并增加向下落地的石座。
- 侧栏 `01 — ∞` 改为“探索无界”。版本保持 1.0.0，其它功能保持原样。
- 本次仅执行类型检查与正式构建，不重复全面功能验收。下方验收记录属于定稿微调之前的 1.0.0 构建；最新 EXE 校验值在本目录 `SHA256.txt`，原回归报告保留其实际被测文件的校验值。

## 前一轮验收范围

- 55 项单元与接口检查通过。
- 100 个面板状态在 1500×960、900×650 两种窗口下检查通过，未发现横向溢出或按钮文字裁切。
- 10 个展品、猫咪造型和 3 个远景岛屿的 32 张多角度渲染，以及四区域全景、中心、码头、镜面、杯体和标牌检查通过。
- AI 山径、CNN 捷径双向行走，跳跃落地、地形接缝及 54 段栏杆检查通过；28 处雪堆保持浅层并避开道路和家具。
- 19 件照片／专辑作品均能步行抵达并按 F 打开对应作品；16 个 R 小互动和记忆收集持久化检查通过。
- 五个本地模型完成真实推理；XiangLM 与双盲诗在完成生成前持续输出中文内容。
- 24 份音轨完成响度测量；12 首专辑曲目和 MV 的播放输出、切换、静音与背景恢复检查通过。七首伴奏自动轮播、季节曲旅程去重检查通过。
- 四种天气过渡、雨雪世界坐标、图标对齐、摄影天气冻结、港口通行与关闭航线检查通过。
- 成品独立模型目录、58 个本地媒体地址和 2 份论文复核通过；34 张图片及缩略图全部解码，完整 MV 全片解码无错误，包内 63 个媒体与模型工作文件逐一比对一致。
- 记忆星图、全部碎片、摄影自由相机、明信片 PNG 导出、退出摄影时的光照平滑恢复及跨项目传送检查通过。
- 前一轮 EXE 的首次启动、重复启动和刷新资源检查通过。Windows 真实 Esc 在长时间打开的帮助、星图、索引、天气和产品界面中恢复环顾；再次 Esc 释放鼠标。校验报告绑定当时被测 EXE 的 SHA256。

自动检查与多角度巡检覆盖当前路径和场景，不等同于穷举所有观察角度。科研界面保留论文方程和演示参数说明；远方三座岛屿依然是未开放区域。

性能对照：1280×800、倍率 1、AMD Radeon 610M / ANGLE D3D11，同机固定视点测量。AI 入口约 23→47 FPS，科学约 43→55、博物馆约 41→55、夏岛约 45→64；总览约 44→41，存在采样波动。该结果不代表所有设备、分辨率和观察方向，未宣称全场景稳定 60 或 120 FPS。

## 运行与维护

双击 `build/XiangMeta-1.0.0/XiangMeta-1.0.0-x64.exe`。需要移动时复制整个 `XiangMeta-1.0.0` 文件夹，保留旁边的 `runtime/` 与 `local.json`。

开发源码、素材原稿和独立运行环境仍保存在工程内；版本说明集中在 `docs/releases/`。当前验收记录位于 `artifacts/current/`。

正式版验收后清理约 13.00 GiB 的旧版成品、重复打包产物和旧测试资料，详见 [清理记录](../../maintenance/release-1.0-cleanup.md)。
