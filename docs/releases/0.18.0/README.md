# v0.18 庭院与远航

## 猫咪与近景模型

- 猫咪改为蜷坐轮廓，后腿收在身体下方，前方只露两只短小脚掌。重新调整头身比例、三角耳、鼻口和胡须，尾巴从身体后侧沿地面绕回，采用渐细曲线和封闭尾尖。
- 检查十个展品模型的正侧背面：诗园桌面补齐支撑，凳脚落地，散落圆球改为小花盆；塔身补上底座，收短孤立细柱。
- 树冠增加细微起伏和重叠层次，继续共享几何与静态合批。
- 四区共新增 19 处低矮庭院装饰：种植盆、果枝、碎石、暖色小灯、贝壳与漂流木。放置时避开道路、家具、作品观看点、碎片和互动装置；山脉只保留一处符合坡度及留白条件的新增装饰。

## 山脉入口小幅整理

- 纸蝶移至礼物驿站侧后方，并缩小基座；入口牌缩小、向岛沿侧移，首个碎片向前庭边缘错开。
- 新增局部 arrivalCourt，柔化入口左侧坡肩；道路、五级平台、上山顺序和 CNN 捷径保留。地形渲染与行走继续读取同一个高度函数。

## 三座远景岛

- 量化投资交易所岛：临海柱廊、玻璃研究大厅、烛形数据雕塑与开放数据中庭。
- 机器人岛：中央关节机器人、两侧装配工坊、机械臂夹爪和小型滚筒装配线。
- AI 研究院：穹顶实验室、完整露出屋顶的神经网络天线、两翼研究单元和庭院装置。
- 三岛重新布置支撑台地、岸石、种植带、步道、庭院灯与靠泊平台，去掉遮进建筑中的山包。远方岛屿菜单增加研究院远眺；港口三条航线继续保持未开放。

## 字体和界面

- 使用本机现代无衬线字体序列，改善小字字号、字距、对比度和数字显示，减少旧式等宽小字的颗粒感。
- 三维标牌采用 1536 像素宽画布、按实际字宽排版、更大的正文比例与各向异性过滤，避免横向压扁字形。
- 界面统一圆角、轻边框、柔和层次和更清晰的标签；保留深色标题栏、连续底部栏及照片原比例瀑布流。
- 切换摄影模式或改变窗口尺寸时立即补绘一帧，避免画布调整大小后的短暂空白。

## 检查范围

十个展品、猫咪与三座远景岛共 32 张多角度模型检查图；另检查四区现场、三个远眺画面、桌面常规/最小窗口和三档照片界面。检查记录位于 artifacts/model-audit-v18.json 与 artifacts/world-review-v18.json。

47 项单元检查、16 个互动从入口实走触发及进度恢复、山路与 CNN 捷径双向行走、五级传送和跳跃着地均通过。风车完整转动、三种天气连续性、船体及 MV 屏幕多视角检查通过。

五张专辑和十四幅照片的观看位置全部实走可达；F 能打开对应作品，抬头离开目标后不继续误选。记忆星图连线和碎片界面的底部留白检查通过。

最终版本在本机 1280×800 无头浏览器短时抽样：行走约 56 FPS，各区域约 57–71 FPS，总览约 53 FPS；结果见 artifacts/performance-v0.18-final.json。这是短时检查，不代表所有设备或所有天气场景稳定 60 FPS。

最终 EXE 的 63 个媒体及模型适配文件与工程原件哈希一致；19 张封面和照片在首次启动、重复启动与刷新后均能解码，音乐、MV 播放跳转和两篇论文工作台通过。Windows 物理 Esc 在本轮 EXE 检查中明确跳过，未计入通过项。

发布目录为 build/XiangMeta-0.18.0。完整目录包含模型和独立 Python，移动时保留整个文件夹。
