# 分阶段建设与素材清单

## Phase 1：基础世界

本次已实现：世界生成、四区与枢纽、玩家、摄像机、基础碰撞、展品交互、模块发现、内容 schema、成长档案、存档、资产与音频路径规范。

当前以桌面键鼠为主。窄屏保留可访问的展品界面，但还没有移动端虚拟摇杆。

## Phase 2：模型与 Agent

本次实现五个原项目的独立适配器、统一模型网关、取消/超时、图片输入和摄像头生命周期。世界 NPC 提供资料导览并连接到配置的真实语言模型。

后续重点：可恢复的流式生成、常驻进程空闲释放、GPU 环境选择、模型版本契约、基于项目资料的检索增强、Agent 工具权限。

## Phase 3：真实展馆内容

本次已搭建各馆结构及占位。科研目录保持外部资料源，未自动把全部实验文件、公司材料导入世界。下一步用选择过的资料充实展品。

需要统一补齐的素材：

| 区域 | 需要内容 | 目标位置 |
|---|---|---|
| AI 山脉 | 项目封面、训练曲线、架构图、希望公开的截图 | 对应模块的媒体与成长档案 |
| 猫咪森林 | 公开展示的猫咪照片、编号到姓名映射、介绍 | 猫咪展览素材；不直接公开完整训练集 |
| Bubble | 实验装置图、代表性视频、量纲/单位、可公开的参数数据和结论 | 科研模块的数据与媒体 |
| 声致发光 | 装置照片、实验记录、可展示数值曲线、求解脚本的验证条件 | 独立科研适配器 |
| 摄影展廊 | 猫咪/风景/日常原作，标题、日期、地点、文字说明 | photography 模块 |
| 个人作曲 | 个人原创/编曲音频、封面、署名、创作年份、个人 MV | personal-music 模块 |
| 未名拾音 | 《燕来有声》封面、团队介绍、制作名单、品牌图形 | weiming 模块 |
| 全世界 | 轻音乐、环境音、UI 声音、交互声音 | 音频清单四条音轨与区域映射 |
| 建筑/角色 | 希望采用的统一美术参考，GLB 模型与动画 | visualAsset，后续角色系统 |

不必一次提供全部素材。优先从一件个人作品和一个 AI 项目的完整展览开始验证替换流程。

## Phase 4：视觉与发布

已具备占位建筑、阴影、雾、低性能模式、GLB 资源替换与 EXE 构建。

后续：统一美术、专业灯光、空间音频、区域淡入淡出、场景分区加载、真实室内空间、可配置碰撞、Windows 图标/签名/安装包/版本更新。正式对外发布前再检查作品署名与依赖许可。

## 保持长期可维护

- 源项目继续独立迭代，XiangMeta 保存适配器与展示信息。
- 不把 checkpoints、datasets、EXE、node_modules、Python 环境加入源码库。
- 模型版本与展览事实分别管理；模型变更后做真实推理验收。
- 优先实现可复用交互契约；仅在验证需要后扩展类型，避免按项目 ID 添加分支。
- 世界与模块 schema 升级时显式迁移；不要悄悄改变旧字段含义。
