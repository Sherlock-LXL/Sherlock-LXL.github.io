# 四季游乐

入口：侧栏「四季游乐」打开总览；靠近四岛上的游乐摊位按 V 打开该摊位的专属页面，页面内可切换「所有游戏」。冬季摊位直接显示游艺室选单。支持桌面键盘和触屏。游戏页保留简短规则，赛道页与驾驶 HUD 的完整按键说明折叠在「操作」中。

| 季节 | 体验 | 操作 |
| --- | --- | --- |
| 春 | 四岛环游摩托；约 309 m / 圈，经过现有山路、四岛庭院和桥梁 | WASD 油门、倒车与转向；Shift + 转向漂移；空格刹车；E 加速 |
| 夏 | 群岛穿桥快艇；约 532 m / 圈，沿四岛海岸与桥拱水道航行 | WASD 油门、倒车与舵向；空格刹车；Shift 加速 |
| 秋 | 山海长空巡游；约 432 m / 圈，连续高低转场 | W 俯冲、S 抬升、AD 倾斜转弯、空格空气刹车；金色气流补充高度 |
| 冬 | 方块消除、穿边贪吃蛇、无尽打砖块、2048、翻牌配对、落球合成 | 每款游戏显示操作提示；键盘、按钮或画布触屏操作 |

三个赛道的计时挑战和自由漫游均先显示「准备出发 · 3 → 2 → 1」，再开始运动。倒计时从首次渲染启动，单帧最多推进 0.1 秒，避免初次着色器编译跳过数字。按顺序正向穿过全部信标，完成两圈。R 或驾驶 HUD 的 R 按钮复位到上一个信标，再倒计时三秒；倒计时期间载具和计时静止，每次复位的五秒罚时在最终结算单独加入，HUD 主计时只显示驾驶用时。倒计时中不能重复复位。休闲模式不显示路线、不判圈、不计罚时。P / Esc 或屏幕暂停按钮可暂停、继续、重新游玩和退出；切走窗口时自动暂停。退出载具后返回所在摊位的安全入口。

摩托的车架、发动机、悬架、辐条轮和骑手握把使用紧凑尺寸；转弯时车架轻微侧倾、前轮转向。碰撞范围为半径 0.35 m、前后各延伸 0.64 m 的胶囊，以五个采样点覆盖车身；接触时保留沿障碍运动，已有重叠允许逐步退出。每个障碍分别检查，避免退出动物重叠时进入邻近的墙。低台阶仍由共享行走逻辑处理。漂移让车头快速入弯，同时保留短暂侧滑；松开 Shift 恢复抓地。独立加速消耗蓄能，耗尽后需松开按钮并恢复至少四分之一再启动；松开加速会自然减速。快艇碰撞使用贴近船身的胶囊范围，接触时可沿岸滑动；反向油门先制动再倒车，转向不会将船身卡入岸边。滑翔伞巡航约 11 m/s，俯冲不超过 19 m/s；圆环半径 6 m，判定额外容许 1.25 m 擦边。打开原世界面板会暂停计时，关闭后继续；游戏中的 P 优先用于暂停。计时按实际经过的秒数计算，物理碰撞仍用短步积分。驾驶时动物保持活动并对靠近的载具让路。

竞速仅突出当前和下一个信标，第三个透明显示，后续隐藏；小地图使用相同顺序。3D 路线只显示当前分支附近约 42 m，光点沿前进方向循环流动。减少动态效果设置会将路线显示为静态，气流用近处的上升金色光点表示，避免与信标圆环混淆。

成绩按赛道长度和参考均速设置金、银、铜三级；目标时间显示在赛道页的「操作」中，依次配烟花、星芒、光点。竞速记录取最短总用时，小游戏取最高得分。陆海赛道用 `xiangmeta.games.v1.race.<season>.2`，减速后的空中赛道用 `xiangmeta.games.v1.race.autumn.3` 存入本浏览器 localStorage。方块、贪吃蛇和翻牌使用 `xiangmeta.games.v1.arcade.<id>.v2`，打砖块清行补砖规则使用 `xiangmeta.games.v1.arcade.bricks.v3`；2048 沿用原分数，落球合成用 `xiangmeta.games.v1.arcade.falling`。旧纪录保留在原键中，不与新规则混算。存储失败仍可游戏，结算会说明未保存。

## 游艺室规则

- 方块消除：初始每格 0.52 秒，随有效游戏时间、消行数和落块数平缓提速，最快每格 0.15 秒。
- 贪吃蛇：上下左右均可穿边；撞到自己仍会结束。
- 无尽潮汐：新砖行缓慢下移，间隔从约 16 秒平滑缩短至 8 秒；每消完一整行也立即补一行，并重置自动补行进度。新行与旧砖保持间隔。球速随时间和击中次数提升，最高 2.5 倍。砖块抵达红线或三次漏球后结束。
- 2048：达到 2048 后继续合并，直到无路可走。移动约 85 毫秒、新块出现和合并反馈约 35 毫秒，总动画 120 毫秒；支持连续输入缓冲和减少动态效果设置。
- 翻翻乐：初始 200 分，每次有效翻开一张扣 5 分，每对加 100 分，完成加 400 分；只保存完成局的最终成绩。
- 四季叠叠球：移动鼠标或拖动选择落点，点击 / 松手投球；键盘左右移动、空格投球。相同等级小球碰撞会合成更大的球并得分，共九级，下一颗和随后一颗会提前显示。投球间隔 0.24 秒，新球落底约 0.58 秒；地面与球间碰撞会短暂压缩、回弹，合成显示扩散光圈。减少动态效果设置关闭压缩与光圈。小球采用短步圆形碰撞，叠到上方虚线并持续超过宽限时间后结束；支持暂停、重开和本地成绩。

## 实现边界

- `shared/seasonal-games.mjs`：赛道、扫掠信标判定、计时、成绩和载具物理，无渲染依赖。
- `shared/bike-contact.mjs`：摩托车身采样、接触法线、沿障碍滑动与重叠退出。
- `shared/game-routes.mjs`：基于实际障碍的陆地路线规划、海空曲线路线及水域通行；`shared/bridge-layout.mjs` 由桥梁模型与船只碰撞共用，区分桥拱与石墩。
- `shared/arcade.mjs`：六款小游戏状态机；`shared/falling-merge.mjs` 提供落球的碰撞与合成，`src/world/arcade-room.ts` 按需加载，负责 Canvas 绘制与输入。
- `shared/race-guidance.mjs`：按信标顺序选择路线分支；`src/world/route-guide.ts` 使用复用的顶点缓冲绘制局部路线和流动光效。
- `src/world/seasonal-games.ts`：摊位安全放置、游戏生命周期、追随镜头、交互、HUD 与特效。
- `src/world/game-models.ts`：沿用原世界材质和建筑构件的程序化载具、骑手与摊位。
- `World` 仅增加生命周期、输入互斥和相机切换；保持中央枢纽、原始四岛、地形与展览模块。
- 摩托使用车身接触求解与共享地形、台阶逻辑；快艇受近岸安全边界约束；滑翔伞撞到地面或建筑、飞出世界范围时复位。所有模式都可手动复位。
- 临时赛道、尾迹和结算粒子在退出时释放；不增加图片下载、外部服务或第三方运行依赖。

人物自动跨越不高于 0.48 m 的小台阶，骑乘可跨越 0.55 m。物理立即解决地面支撑，视角和坐骑模型在短时间内平滑抬升，跳跃不受影响。骑乘支持岛屿、连接桥和中央枢纽的连续地面，依旧拒绝无支撑的海面和穿墙。下骑后动物会把新位置作为活动中心。花园长椅的靠背、竖杆与顶横梁共用连接座面的倾斜支架。

## 验证

`npm test` 覆盖移动、摩托贴墙绕行与动态重叠退出、船只滑动与倒车、正逆向信标、擦边判定、完整两圈、复位停表、存储容错、局部路线及六款小游戏核心规则。落球检查覆盖不同帧率下的落底时间、碰撞回弹、快速稳定与地面防穿透。

构建并启动预览后运行 `npm run test:games`。默认预览为 `http://127.0.0.1:4191/world/`，测试截图和场景数据写入 `/private/tmp/seasonal-review`。可用 `GAME_ORIGIN`、`GAME_ARTIFACTS`、`GAME_ENGINE=webkit`、`GAME_TOUCH=1` 切换环境。浏览器检查使用低画质减轻自动化环境的 WebGL 负担；真实指针和键盘操作验证入口、驾驶、暂停、复位、退出及每款街机。`tests/tour-navigation.mjs` 使用浏览器导出的真实碰撞体验证三种载具完整两圈、四岛覆盖和零碰撞通行。

`npm run test:game-experience` 用真实按键完成快艇与滑翔伞两圈，验证等级结算、重开、P / Esc、原世界面板暂停、小游戏暂停与重启、翻牌完整胜利及刷新后成绩保留。`npm run test:mounts` 骑北极熊从冬岛穿过桥梁与枢纽抵达春岛，验证安全下骑和新的活动中心。Chromium 触屏检查包含双指同时油门与转向，以及单独松开转向后继续加速。

`npm run test:arcade` 通过真实操作验证穿边、2048 快速连续输入、按张扣分、无尽模式的新砖行下移，以及落球合成的连续投球、合成、暂停与重开。浏览器检查同时验证四个专属摊位页、「所有游戏」、三个赛道的完整起步倒计时、信标可见范围和三秒复位停表。
